# YouTube新着ダイジェスト

登録しているYouTubeチャンネルの新しい動画を、**まだ知らない情報だけ**に絞って要約し、iPhoneの声で読み上げるウェブアプリです。iPhoneのSafariだけで使えます（ホーム画面に追加するとアプリのように使えます）。

## できること

| 要件 | しくみ |
|---|---|
| iPhone単体で完結 | Safariで動くウェブアプリ。サーバーは不要で、データはiPhoneのブラウザの中だけに保存 |
| 追加の課金なし | 要約はGemini APIの無料枠、新着の取得はYouTube Data APIの無料枠（1日10,000ユニット）、読み上げはiPhone内蔵の声 |
| 音声で読み上げ | 「要約を聞く」「未聴をすべて聞く」。下のバーで一時停止・次へ・停止。声と速さは設定で変更 |
| 新しい情報だけを抽出 | Geminiが動画（URL）を直接見て、あいさつや宣伝を除き、新しい情報・独自の視点だけを出す |
| 既知の内容は除外 | 要約した内容は「既知」タブに短い事実として自動で記録され、次からの要約で照合して省く。省いた内容は「既知のため省いた内容」で確認できる。自分で知っていることを追加・削除もできる |
| 段階的な深掘り | 各ポイントの「詳しく」→「さらに詳しく」→「動画で確認」（動画を見直して答える）。自由な質問もできる。回答は自動で読み上げ |
| チャンネルを選ぶ | 「チャンネル」タブでチェックを入れたチャンネルだけが要約の対象。新着タブでチャンネルごとに絞り込みもできる |

## はじめに（最初の1回だけ・約10分）

### 1. Gemini APIキーを作る（無料）
1. iPhoneのSafariで https://aistudio.google.com/apikey を開き、Googleアカウントでログイン
2. 「APIキーを作成」→ 表示されたキーをコピー
3. このアプリの「設定」→「Gemini APIキー」に貼り付けて「保存」

※ 無料枠では、入力した内容がGoogleのサービス改善に使われることがあります（Googleの利用規約による）。

### 2. YouTube Data APIを使えるようにする（無料）
1. https://console.cloud.google.com/apis/library/youtube.googleapis.com を開く
2. 上のプロジェクト選択で、手順1でキーを作ったプロジェクト（「Gemini API」などの名前）を選び、「有効にする」
3. そのままGeminiのキーで動けば完了。「APIキーが制限されている」というエラーが出たら、「認証情報」→「認証情報を作成」→「APIキー」で新しいキーを作り、設定の「YouTube Data APIキー」に入れる

### 3. 要約したいチャンネルを入れる
「チャンネル」タブで、次のどれかの方法で追加し、**要約したいチャンネルにチェック**を入れます。

- **1つずつ追加**：`@ハンドル`、チャンネルのURL、チャンネル名を入れて「追加」（追加したものは最初からチェック済み）
- **Google TakeoutのCSV**（いちばん簡単に全部取り込める）：https://takeout.google.com で「YouTube と YouTube Music」だけを選び、「すべてのYouTubeデータを含める」で「登録チャンネル」だけにして書き出し → 届いたZIPをiPhoneの「ファイル」アプリで開いて `subscriptions.csv` を選ぶ
- **登録チャンネルが公開設定の場合**：自分のチャンネルの`@ハンドル`を入れて「取り込む」（YouTubeの設定 → プライバシー →「登録チャンネルを非公開にする」をオフ）
- **Googleでログイン**：Google CloudでOAuthクライアントID（ウェブアプリ、承認済みのJavaScript生成元にこのアプリのURLのドメイン）を作り、設定に入れる。OAuth同意画面を「テスト」にして自分をテストユーザーに追加する。手間が多いので、上の方法で足りればそちらがおすすめ

まとめて取り込んだチャンネルは、最初はチェックが外れています。要約したいものだけ選んでください。

## 毎日の使い方

1. 「新着」タブで **新着を要約** を押す（選んだチャンネルの、設定した日数以内の新しい動画を探して順に要約）
2. **未聴をすべて聞く** で、古い順に続けて読み上げ。聞き終わった動画は「聞いた」になる
3. 気になったポイントで **詳しく**。さらに知りたければ **さらに詳しく**、正確さを確かめたいときは **動画で確認**
4. 質問欄に聞きたいことを入れて **質問**（キーボードのマイクで音声入力もできる）

## 無料枠について

- **Gemini**：無料枠には1分あたり・1日あたりの回数と量の上限があります。上限に達するとメッセージが出て要約が止まるので、時間をおいて「未要約をすべて要約」を押せば続きから再開できます。
  - 長い動画ほど量を使います。設定の「動画の解析の細かさ」を小さく（0.1）すると節約できます（話中心の動画なら0.1で十分です）。
  - 「詳しく」「さらに詳しく」「質問」は、要約のときに作った詳細ノートを使うので軽く、すぐ返ってきます。「動画で確認」は動画を見直すので、要約と同じくらい量を使います。
  - 新しい無料モデルが出たら、設定の「モデル」の「一覧」から選べます。
- **YouTube**：新着の確認は1チャンネルあたり約1ユニット。チャンネル名での検索追加だけ100ユニット使います。
- **Claude Proについて**：Claude Proのプランには、アプリから呼び出せるAPIが含まれず、またClaudeはYouTube動画を直接見られないため、このアプリはGeminiの無料枠を使っています。

## iPhoneでの注意

- 画面を消したり別のアプリに切り替えたりすると、読み上げが止まります（Safariの制限）。聞くときは画面をつけたままにしてください。
- 読み上げの声は「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」から高品質な声（例：Kyoko（拡張））をダウンロードすると、より自然になります。
- データ（チャンネル・要約・既知）はこのiPhoneのSafariの中だけにあります。消えると困る場合は「設定」→「バックアップを保存」をしてください。APIキーはバックアップに入りません。
- APIキーはiPhoneのブラウザの中にだけ保存されます。念のため、Google CloudのキーにHTTPリファラー（このアプリのURL）の制限を付けておくと安全です。

## 置き場所（公開のしかた）

静的なファイルだけなので、GitHub Pagesなどにそのまま置けます。このリポジトリでGitHub Pagesを有効にした場合のURLは `https://<ユーザー名>.github.io/<リポジトリ名>/yt-digest/` です。iPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」。

ローカルで動かす場合：

```
python3 -m http.server 8000
# http://localhost:8000/yt-digest/ を開く
```

## ファイル

- `js/youtube.js`：登録チャンネルの取り込み、新着動画の取得（YouTube Data API）
- `js/gemini.js`：要約（既知の除外）と深掘り（Gemini API）。プロンプトはここ
- `js/speech.js`：読み上げ（iPhone内蔵の声。長文は文ごとに分けて読む）
- `js/store.js`：保存（localStorage）
- `js/app.js`：画面
